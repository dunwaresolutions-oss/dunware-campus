## 5. Positioning Map

```
                    HIGH COMPLIANCE / DATA CONTROL
                              ↑
                              │
                    ┌─────────┼─────────┐
                    │         │         │
              Campus   Skyward   Procare
              (only)  (on-prem) (hybrid)
                    │         │         │
                    └─────────┼─────────┘
                              │
                    LOW ←──────┴──────→ HIGH
                   EASE OF BUY / DEPLOY
                    (Cloud SaaS)    (On-prem)
```

- **Campus** owns the **top-left quadrant**: maximum compliance/control, but higher deploy friction.
- **Skyward** is the only K–12 SIS with real on-premise — but no daycare, no field encryption, no audit log.
- **Procare** has hybrid but legacy on-prem; no encryption/audit/retention.
- **All cloud SaaS** (Brightwheel, HiMama, PowerSchool, Infinite Campus) cluster bottom-right: easy buy, low control.

## 6. Competitive Advantages (Campus Moats)

| Moat | Evidence | Durability |
|------|----------|------------|
| **Only on-premise with full PII encryption** | AES-256-GCM fields + docs, key never in DB/repo/logs | High (hard to retrofit) |
| **Append-only audit log (reads + writes)** | `AuditEntry` + middleware + signals + mixins, tested | High (architectural) |
| **Retention/erasure + legal hold** | `retention_sweep`, `erase_person`, `legal_hold`, drilled | High (regulatory) |
| **Object-level permissions on every endpoint** | `IsObjectOwnerOrStaff` + `visible_queryset`, matrix-tested | High (codebase-wide) |
| **Versioned consent (append-only)** | `Consent.current_for()`, portal capture | Medium (copyable) |
| **Check-out authorization rule** | `AuthorizedPickup` + `GuardianLink.can_pickup`, enforced in service | Medium (domain logic) |
| **Single Windows installer (no Docker/Python/Node)** | PyInstaller + Inno Setup + bundled Postgres/Caddy/NSSM | Medium (packaging effort) |
| **Flat pricing vs per-child** | $79–$499/mo regardless of enrollment | Low (pricing easily copied) |
| **Multi-currency + hosted checkout (PCI SAQ-A)** | Paystack/Flutterwave/Stripe, encrypted keys | Low (integrable) |

## 7. Competitive Disadvantages (Gaps)

| Gap | Severity | Mitigation |
|-----|----------|------------|
| **No mobile app (staff or parent)** | High | PWA works offline; native app = Phase 11+ |
| **No multi-site / district mode (yet)** | High | `deployment_mode: HEADQUARTERS` reserved; schema supports it |
| **Single-founder, no sales team** | High | Pilot-first, channel partners (MSPs, IT VARs) |
| **Windows-only target** | Medium | 95%+ of target schools on Windows; Caddy + waitress portable |
| **No public API / webhook ecosystem** | Medium | DRF API exists; webhooks = Phase 11 |
| **No LMS integration (LTI, OneRoster)** | Medium | Grades export covers reporting; LTI = Phase 12 |
| **Brand unknown, no references** | High | Pilot program → case studies → referrals |

## 8. Win/Loss Themes (For Sales Conversations)

| Scenario | Win Theme | Loss Risk |
|----------|-----------|-----------|
| **Public school / district (IT mandates on-prem)** | "Only SIS+daycare that runs on your server, with audit log + encryption + retention" | "We need multi-school from day one" → HQ mode not ready |
| **Indigenous / band-operated school** | "Data never leaves your building. PIPEDA + FIPPA + OCAP-aligned controls built-in" | "No IT staff to maintain Windows server" → MSP partner |
| **Daycare chain (5–20 sites)** | "Flat pricing = predictable. On-prem = no per-child cost as you grow" | "We want cloud + mobile app for directors" → PWA + roadmap |
| **Montessori / Waldorf (narrative grading)** | "Rubric + narrative + marks schemes, frozen at report-card generation" | "We use Transparent Classroom" → niche, no billing/scheduling |
| **Private school (tuition + SIS)** | "Integrated billing (invoices + hosted checkout) + full SIS + portal" | "We're on Veracross/Blackbaud" → switching cost high |

## 9. Pricing Positioning Statement

> **Campus is the only flat-priced, on-premise, compliance-first platform covering daycare through small secondary.**
>
> - vs **Brightwheel/Procare/HiMama**: You pay per child forever. Campus caps at $499/mo for 1,500 students. On-prem = your data, your server, your encryption key.
> - vs **PowerSchool/Skyward/Infinite Campus**: Built for districts, not single schools. No daycare. No field encryption. No audit log. Campus is purpose-built for ≤1,500 students, single-tenant, with PII controls a childcare license *requires*.
